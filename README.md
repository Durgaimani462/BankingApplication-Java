# BankingApplication-Java
Simple Java console banking application (learning project)

This is a simple console-based Banking Application developed using Java.

## Features
- Check balance
- Deposit amount
- Withdraw amount
- View previous transaction

## Purpose
This project was created for **learning and practice purposes**.
I learned the core idea from online tutorials and implemented the code myself
with small modifications and fixes.

## Concepts Used
- Java classes and objects
- Scanner class
- Switch case
- Methods
- Basic OOP principles

## Note
This is a beginner-level project and not intended for real banking use.
